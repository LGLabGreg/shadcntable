## Overview

shadcntable is built on [TanStack Table v9](https://tanstack.com/table) and shadcn/ui. The hook owns the table state. Each component takes the table instance, so you can place, restyle or replace them one by one.

| Export                        | File                              | Purpose                                   |
| ----------------------------- | --------------------------------- | ----------------------------------------- |
| `useDataTable`                | `use-data-table.ts`               | Creates the table instance                |
| `DataTable`                   | `data-table.tsx`                  | Renders the header and rows               |
| `DataTableToolbar`            | `data-table-toolbar.tsx`          | Global search, filter reset, view options |
| `DataTablePagination`         | `data-table-pagination.tsx`       | Page navigation and page size             |
| `DataTableColumnHeader`       | `data-table-column-header.tsx`    | Sort and hide menu, filter popover        |
| `DataTableViewOptions`        | `data-table-view-options.tsx`     | Column visibility menu                    |
| `createSelectionColumn`       | `data-table-selection-column.tsx` | Checkbox column for row selection         |
| `createDataTableColumnHelper` | `lib/features.ts`                 | Typed column helper                       |
| `DataTableLocaleProvider`     | `lib/locale.tsx`                  | Translations                              |

## Installation

```bash
pnpm dlx shadcn@latest add https://shadcntable.com/r/data-table.json
```

## Usage

```tsx
'use client'

import { DataTable } from '@/components/shadcntable/data-table'
import { DataTableColumnHeader } from '@/components/shadcntable/data-table-column-header'
import { DataTablePagination } from '@/components/shadcntable/data-table-pagination'
import { DataTableToolbar } from '@/components/shadcntable/data-table-toolbar'
import { createDataTableColumnHelper } from '@/components/shadcntable/lib/features'
import { useDataTable } from '@/components/shadcntable/use-data-table'

type User = { id: string; name: string; email: string }

const columnHelper = createDataTableColumnHelper<User>()

const columns = columnHelper.columns([
  columnHelper.accessor('name', {
    header: ({ column }) => <DataTableColumnHeader column={column} />,
    meta: { label: 'Name' },
  }),
  columnHelper.accessor('email', {
    header: ({ column }) => <DataTableColumnHeader column={column} />,
    meta: { label: 'Email' },
  }),
])

export function UsersTable({ users }: { users: User[] }) {
  const table = useDataTable({ columns, data: users, getRowId: (user) => user.id })

  return (
    <div className='space-y-4'>
      <DataTableToolbar table={table} />
      <DataTable table={table} />
      <DataTablePagination table={table} />
    </div>
  )
}
```

## useDataTable

`useDataTable` wraps TanStack Table's `useTable` and registers the features the components need: sorting, column and global filtering, pagination, row selection and column visibility. It accepts [every TanStack Table option](https://tanstack.com/table/latest/docs/api/core/table). The most common ones are below.

<PropsTable id='useDataTable' />

### State

Each piece of state (`sorting`, `columnFilters`, `globalFilter`, `pagination`, `rowSelection`, `columnVisibility`) has one owner:

- **The table.** This is the default. Read state from `table.state` and change it with methods such as `table.setSorting` or `column.toggleVisibility`.
- **The table, with a starting value.** Pass `initialState`, for example `{ pagination: { pageIndex: 0, pageSize: 25 } }`.
- **You.** Pass the value in `state` and its matching `on[Slice]Change` callback.

```tsx
const [sorting, setSorting] = useState<SortingState>([{ id: 'name', desc: false }])

const table = useDataTable({
  columns,
  data,
  state: { sorting },
  onSortingChange: setSorting,
})
```

## Filters

Set `meta.filter` on a column to add a filter popover to its header. `useDataTable` gives the column the matching filter function. A `filterFn` you set on the column yourself takes precedence.

<PropsTable id='filterConfig' />

| Variant       | Input                | Filter value                 | Matches when                                          |
| ------------- | -------------------- | ---------------------------- | ----------------------------------------------------- |
| `text`        | Debounced text input | `string`                     | The value contains the text, ignoring case            |
| `select`      | Single select        | `string \| number`           | The value equals the option                           |
| `multiSelect` | Searchable checklist | `(string \| number)[]`       | The value, or any item of an array value, is selected |
| `numberRange` | Min and max inputs   | `[min?, max?]`               | The value is within the range (inclusive)             |
| `dateRange`   | Range calendar       | `{ from?: Date, to?: Date }` | The date is within the range, whole days inclusive    |
| `custom`      | Your component       | Anything                     | Your column's `filterFn` returns `true`               |

A missing end of a number or date range leaves that side open.

### Custom filters

A custom filter provides the input as `component` and the matching logic as `filterFn`:

```tsx
columnHelper.accessor('age', {
  header: ({ column }) => <DataTableColumnHeader column={column} />,
  filterFn: (row, columnId, adultsOnly: boolean) =>
    !adultsOnly || row.getValue<number>(columnId) >= 18,
  meta: {
    label: 'Age',
    filter: {
      variant: 'custom',
      component: ({ value, onChange }) => (
        <Checkbox
          checked={value === true}
          onCheckedChange={(checked) => onChange(checked === true || undefined)}
        />
      ),
    },
  },
})
```

Call `onChange(undefined)` to remove the filter.

## Row selection

Add `createSelectionColumn<TData>()` as the first column. It adds a checkbox for each row and a "select all" checkbox for the current page in the header.

```tsx
const table = useDataTable({
  columns,
  data,
  getRowId: (user) => user.id,
  enableRowSelection: (row) => row.original.status === 'active',
})

const selectedUsers = table.getSelectedRowModel().rows.map((row) => row.original)
```

## Row clicks

```tsx
<DataTable table={table} onRowClick={(row) => router.push(`/users/${row.original.id}`)} />
```

A clickable row can take keyboard focus and responds to <kbd>Enter</kbd> and <kbd>Space</kbd>. Clicks on buttons, links, checkboxes and menu items inside the row don't count as row clicks.

## Loading states

Pass `isLoading` for the first load and `isFetching` for background refreshes. `isLoading` shows skeleton rows, and `isFetching` shows a spinner over the rows you already have.

```tsx
<DataTable table={table} isLoading={query.isPending} isFetching={query.isFetching} />
```

## Localization

Wrap your tables in `DataTableLocaleProvider`. Any string you don't override keeps its English default. Strings that include numbers are functions.

```tsx
import { DataTableLocaleProvider } from '@/components/shadcntable/lib/locale'

;<DataTableLocaleProvider
  locale={{
    toolbar: { searchPlaceholder: 'Rechercher...', reset: 'Réinitialiser' },
    pagination: {
      rowsPerPage: 'Lignes par page',
      pageOf: (page, pageCount) => `Page ${page} sur ${pageCount}`,
      rowsSelected: (selected, total) =>
        `${selected} sur ${total} ligne(s) sélectionnée(s)`,
    },
  }}
>
  <UsersTable users={users} />
</DataTableLocaleProvider>
```

For every key, see `DataTableLocale` in `lib/locale.tsx`.

## Server-side data

Set `manualPagination`, `manualSorting` or `manualFiltering`, own that state, and fetch with it. The table then renders your data as given. See the [server-side example](/docs/examples/server-side).
